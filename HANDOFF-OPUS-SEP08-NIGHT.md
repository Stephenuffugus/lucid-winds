Each of these has happened on this project, most of them in the last forty eight hours.

   STATE before the push; never more than forty minutes without a commit on a green tree. If you

   anything else.

   file's section 9 are your memory; write them as if the next reader is a stranger, because it may
   be you after a reset. When context is long, finish the item in hand, write it up, push, and let
   the next context start from section 9's last line. Never start T1.2 or T2.3 with a context that
