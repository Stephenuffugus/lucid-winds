What it is

A single-file, framework-free HTML5/JavaScript game. Eight independent trait layers resolve from hash bytes into a fully rendered SVG plant, each paired with a procedurally generated 7-5-7 haiku unique to that hash. Deterministic end to end.

By the numbers

~140,000 lines single-file ES5, 26 interdependent script blocks
67 mini-games, 85 companions, breeding genetics, 100-point skill tree
Real-world GPS mode with live weather-driven climate simulation
Server-authoritative economy atomic, idempotent, rate-limited Cloud Functions
Pi Network payments, Firebase Auth + Firestore
Own test harness jsdom smoke suite + lint gate

How it was built

Self-taught, no computer science background. Built by directing AI coding systems with real engineering discipline: decomposing a massive system into executable units, holding an architecture strict enough that 26 interdependent blocks don't collapse, and building a verification harness because the failures were silent.

The skill isn't typing. It's decomposition, verification, and debugging at a scale that normally takes a team.
