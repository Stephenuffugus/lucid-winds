# LLM Cross-Check Prompt — paste this with the review doc

Paste the contents of `COMPANION_ITEMS_REVIEW_DRAFT.md` (or attach the file), then add this framing prompt below:

---

I'm the lead designer on a botanical collection game called Lucid Winds. The attached document is a DRAFT proposal for the game's companion ability system + items, synthesized over a long design session. Before I lock it in, I want a fresh outside critique.

**Please review the document and respond on these 6 axes:**

1. **Flavor coherence** — Does each animal's proposed signature ability match its real-world biology or mythological identity? Flag any that feel forced, generic, or mismatched. Be specific (animal name + which mechanic doesn't fit + what would fit better).

2. **Mechanical overlap** — Flag any new signature that mechanically duplicates another signature, a family T2/T3 ability, or an existing keyword. The goal is every ability feels distinct.

3. **Balance risk** — Walk through the synergy combos in section 7. Which look like runaway loops? Which look weak/forgettable? Especially audit:
   - Defender stack (Snail + Spore Web + Garden Spider + Mulch/Bramble/Shellgourd)
   - Compost engine (Compost Song + Worm Tilth + Sacred Roll + Soft Thread)
   - Pollinator engine (Bee + Butterfly + Twin Bloom)
   - Walking-build (Ant Trail + Dragonfly + Cartographer)
   - Climate-resist build (Pangolin + Mammoth + Worm + Scorpion + maybe Koi)

4. **Decision A — Strict rare = ability rule?** Should rare-tagged animals (Jellyfish, Luna Moth, Will-o-Wisp, Origami Crane, Flamingo) get signatures by default, or should signatures stay selective? Argue your position with one paragraph.

5. **Decision C — 6th evergreen keyword?** I currently have 5 (Restless, Hardy, Rooted, Swift, Lush). I tried "Thorned" and "Mycorrhizal" and they failed because they only fit 4-6 animals. Should there be a 6th? If so, propose one that:
   - Fits 8+ different animals naturally
   - Stacks safely (multiple players collecting it doesn't break balance)
   - Hooks into mechanics already in the doc (don't invent new systems)
   - Doesn't overlap the existing 5

6. **Items audit** — Section 6 shows the current 17 items by category and the proposed 3 gap fills. Do the new abilities demand item support that's missing? Do any existing items become obsolete after these abilities ship? Specific item-level recommendations welcome.

**Format your response as 6 numbered sections matching the 6 axes above.** Be terse. Prefer concrete fixes over abstract concerns. If you disagree with my recommendations in section 9, say so directly with reasoning.
