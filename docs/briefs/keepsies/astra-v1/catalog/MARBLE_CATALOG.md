# 240 new marble designs

24 families of ten. These are original genre references, not licensed crossover characters. All tiers and acquisition routes are proposals. The existing 65 are preserved. 14 entries have individual sculpt references; the remaining 226 specify procedural visual designs. None of these entries is wired into the supplied game because no source code was provided.
