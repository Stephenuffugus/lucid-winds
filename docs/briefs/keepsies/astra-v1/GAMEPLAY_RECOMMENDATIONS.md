# The game that earns a favorite marble

These recommendations are proposals for the developer, not implemented changes. Ringer remains the launch priority and the Knuckle remains its signature.

## The first minute
The first calibration launch needs a visible destination: a broad dark catch area beyond the ring, one dust puff on landing and a clear accepted dot. Never require the user to infer whether a snap registered. Separate a canceled gesture from a weak legal shot with different short text. After two unsuccessful attempts, place Recalibrate and the existing accessible input option within thumb reach. Do not hide the fallback behind failure or describe it as lesser play.

After the first break, explain only the next action. If a mib exits: "One out. Your shot again." If none exits: "Nothing out. Dusty's turn." Save spin, warming and poison for the situations where they matter. The written brief is an excellent rulebook and a poor first twenty seconds.

Acceptance: five fresh players, no coaching, four complete calibration and their first match within four minutes. Record failure states without collecting identifying touch data. This is a proposed usability gate, not a measured result.

## Make the cross understandable
The thirteen objects have two roles: scoring mibs and match stakes. Explain once: "Seven wins the match. The winner takes the pot." A player who pockets a rare should not discover later that they did not win it. Use a quiet brass base mark under staked instances, not an altered marble surface. Show an accessible Pot inspector before the break. Keep shooter selection separate from the objects at risk.

Retain physical scale, but solve camera readability. A ten foot ring and a 16 mm mib create a demanding screen ratio. Use bounds-aware framing and a linked top-down inset with large touch controls. Avoid secretly enlarging colliders or snapping aims to opponents. The phone presentation may magnify an inset; the physics cannot.

## Stories on the shelf
Each instance has an event list, not only a type-level description. A useful inspection card reads name, one lore line, latest meaningful event, then optional full history. "Won off Dusty Coyle" matters more than a seventh stat row. A recovered marble gets a visible Returned marker and retains its original UID and cosmetic seed.

Proposed event fields: event id, marble UID, event kind, timestamp, local profile id, opponent id when applicable, match id, source reason. Append only after the authoritative match result and save transaction succeed. Rendering a ceremony must never itself transfer ownership.

A share card is a locally composed image: actual render, name, lore, tier and a user-approved provenance line. Do not include profile identifiers by default. No automatic social posting. The supplied windows are intentionally empty.

## A loss the player can understand
At setup, write the recovery rule immediately beside the stake. A protected marble cannot be selected. An offer must show price, balance, deadline and whether time continues while offline. A tutorial mock ransom is not the normal rule for bosses.

Keep For Fair obvious and fully rewarding as already specified. Rematch should offer the prior rules but ask for a fresh stake selection when inventory changed. Canceling a setup returns everything. Interrupted matches return escrow according to the documented rule. A repeat result event must not pay twice.

## Pouches worth opening
Use three visibly different materials. Show contents tier odds and relevant pity progress before spending. Pity counters and reward assignment save atomically with wallet spend, before animation begins. Allow instant reveal and reduced motion. A beautiful opening cannot fix a missing reward after refresh.

The original table's duplicate-grail reroll to epic is not a guarantee of collection completion. Do not call it a no-duplicate completion system without clarifying that an epic can replace the grail outcome. Keep new family tracks separate until their rates are tested.

## Arena earns its own identity
Once the core sim works, Arena should be about readable future danger. Each hazard telegraphs a discrete next-turn state. Damage marks remain stable while aiming; noisy shimmering cracks do not obscure a small sphere. A low-motion setting uses symbols and written states.

Before finalizing kits, resolve six versus seven conditions, the ring-out refresh ambiguity and the damage units noted in ASSESSMENT.md. Start with The Ring and a small representative bag set. Build Foundry and Glacier after the base match hits its stated shape. Concept boards are not permission to skip the sim gate.

## Useful extras, in order
1. A free shot lab that repeats a saved setup so players can learn backspin without losing possessions.
2. A daily shared seed challenge with local scoring and no server dependence; do not claim a global leaderboard.
3. Collection wishlists and family filters that say where a design can be earned.
4. A favorite marble spotlight using the existing inspect renderer and a rotating local shelf selection.
5. Local pass-and-play with clear profile handoff and independent stake confirmation.
6. A replay bookmark for remarkable shots after deterministic replay is verified in the actual build.

## Phone validation before calling it done
Input: slow snap, fast snap, canceled touch, multi-touch, left hand, right hand, zoom, orientation change, background/resume. Camera: first shot, endgame one target, edge shooter, top-down toggle, no under-floor angle. Economy: crash during ante, crash during result, repeated result event, ransom expiry, insufficient funds, protected UID, duplicate handling. Art: 375 px width, 48 px targets, 140 px insert, grayscale tier recognition, low quality materials, actual payload size. None of these runtime checks can be inferred from supplied stills.
