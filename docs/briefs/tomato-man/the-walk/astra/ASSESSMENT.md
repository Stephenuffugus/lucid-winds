# Walk round

The limp and gallop come from inconsistent leg identity across the four walk cells. This round uses one fixed left-contact, right-pass, right-contact, left-pass cycle, with the same phase beneath all fourteen heads. The far leg stays darker while trading the leading position with the near leg.

The existing idle head and torso provide a stable seat throughout each new cycle. The new walk has no head bob, which is within the two-pixel allowance. Idle, dash and hop remain the downloaded drawings; only the four walk cells are replaced. Hat coordinates for the walk are explicitly supplied so the previous drift is not carried into the new art.
