# Cube Teacher (Stephen 7/17)

**The ask:** "a rubik's cube teacher to teach you how to beat a rubik's cube but make it a fun puzzle to teach people how to do it."

## The design: learn by playing, not by reading
A canvas 3D cube (painter's algorithm — 26 cubelets, flat-shaded faces, drag to orbit, swipe a face to turn; this is well within no-framework canvas work). The teaching is a CAMPAIGN of tiny puzzles, one skill each, beginner method (layer by layer):

1. **The Daisy** — cube is scrambled ONLY a few moves from a white-edge daisy; arrows ghost the move; you do it. 5 puzzles, each one move deeper.
2. **White Cross** — same pattern: start near-solved, finish the cross yourself.
3. **White Corners** (the R U R' U' drill as a rhythm mini-game — repeat the trigger until the corner drops in, the game counts your triggers out loud).
4. **Middle Edges**, 5. **Yellow Cross**, 6. **Yellow Edges**, 7. **Corner Placement**, 8. **Corner Twist** — each stage = 4-6 micro-puzzles + one checkpoint solve.
9. **Graduation**: a full scramble + a hint button that names the stage you're in ("you're at the yellow cross") rather than giving moves.

Every puzzle is generated by applying the INVERSE of the taught step to a solved-through-stage-N cube, so it's always solvable with exactly the skill being taught — machine-provable by construction.

## Scope
Full 3D cube sim + move engine + 8 stage generators. A serious but very contained build (one long session). No IP issues if we never say Rubik's in-game: "Cube Teacher" or Stephen names it.

# BUILD PLAN (added Jul 17 — ready to execute)

## Order of work (one long session, checkpoints in this order)
1. **Cube state + move engine (pure JS, no rendering).** State = 54 stickers
   (6 faces × 9). Moves U/D/L/R/F/B ± and slice-free (beginner method never
   needs M/E/S). Unit proofs: U×4 = identity for all 18 moves; scramble +
   inverse = solved; sexy-move (R U R' U') has order 6. These run in the DEV
   hook forever.
2. **Canvas 3D renderer.** 26 cubelets drawn by painter's algorithm; flat
   quads with per-face color + darkened side shading; orbit by drag on empty
   space; face turns animate by rotating the 9 affected cubelets around the
   axis (~150ms ease). Swipe ON a face row/col = that turn (project swipe
   vector onto the two face-tangent axes, pick the dominant).
3. **Stage generators.** For stage N: take a cube solved through stage N's
   checkpoint, apply the INVERSE of k taught moves (k ramps 1→5 inside the
   stage) using only the stage's move vocabulary. Solvable-with-taught-skill
   by construction; proof = the stage's own solver (scripted move recipes)
   restores it.
4. **Teaching UI.** Ghost arrows on the face to turn (curved arrow overlay,
   pulsing); "why" line in one sentence ("get the white sticker on top");
   trigger-drill stage counts R U R' U' reps aloud with a beat bar. Skip
   button after 2 fails (auto-plays the move slowly).
5. **Campaign shell.** 8 stages × 4-6 micro-puzzles + checkpoint solves;
   stars per stage; Graduation mode = full scramble + stage-naming hint
   button. Free play mode unlocked after stage 3 (timer + move counter).
6. **House kit + portal row** (standard: music, PWA/A2HS, share, DEV
   `?cttest=1` → CT_DEV.proofCheck() = engine unit proofs + every generated
   micro-puzzle solvable by its stage recipe).
