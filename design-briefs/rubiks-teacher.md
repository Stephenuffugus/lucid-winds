# Cube Teacher (Stephen 7/17)

**The ask:** "a rubik's cube teacher to teach you how to beat a rubik's cube but make it a fun puzzle to teach people how to do it."

## The design: learn by playing, not by reading
A canvas 3D cube (painter's algorithm — 26 cubelets, flat-shaded faces, drag to orbit, swipe a face to turn; this is well within no-framework canvas work). The teaching is a CAMPAIGN of tiny puzzles, one skill each, beginner method (layer by layer):

1. **The Daisy** — cube is scrambled ONLY a few moves from a white-edge daisy; arrows ghost the move; you do it. 5 puzzles, each one move deeper.
2. **White Cross** — same pattern: start near-solved, finish the cross yourself.
3. **White Corners** (the R U R' U' drill as a rhythm mini-game — repeat the trigger until the corner drops in, the game counts your triggers out loud).
4. **Middle Edges**, 5. **Yellow Cross**, 6. **Yellow Edges**, 7. **Corner Placement**, 8. **Corner Twist** — each stage = 4-6 micro-puzzles + one checkpoint solve.
9. **Graduation**: a full scramble + a hint button that names the stage you're in ("you're at the yellow cross") rather than giving moves.

Every puzzle is generated by applying the INVERSE of the taught step to a solved-through-stage-N cube, so it's always solvable with exactly the skill being taught — machine-provable by construction.

## Scope
Full 3D cube sim + move engine + 8 stage generators. A serious but very contained build (one long session). No IP issues if we never say Rubik's in-game: "Cube Teacher" or Stephen names it.
