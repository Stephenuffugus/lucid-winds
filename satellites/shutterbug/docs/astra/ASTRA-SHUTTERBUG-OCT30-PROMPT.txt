1. THE GAME
Shutterbug turns a photo of a room into a pixel platformer level. The player photographs a room, and it develops like instant film into a grid of 24 by 48 cells. Shelves and table edges become platforms, shadows become walls, and a thumb sized clay bug climbs the furniture to the ceiling light.
The level is the player's own photo, cut down to the palette and dimmed. You paint NO backgrounds and NO tile sets. You make the small sprites drawn on top of the photo.
Five biomes come from the photo's colours: Attic (browns, oranges), Frost (white, light grey), Deep (blues, teals), Overgrowth (greens), Ember (reds, pinks). Each has one enemy kind.
The live game is optional; you do not need it: https://lucidwinds.com/satellites/shutterbug/ then tap Try the sample room. The live page shows only the hero, the moth, the beacon and the film tab; everything else exists only on the build branch. Every sprite there is a code placeholder that your art replaces.

2.3 Rules for every game file
a. PNG in RGBA. Alpha is 0 or 255, never between.
b. Every visible pixel is exactly one of the 16 hexes. No anti aliasing, blends, soft edges or smoothing.
c. True size only. Never paint large and shrink: that is not pixel art, and the game's colour gate fails it.
d. A 1 px Ink outline around every creature, item and trap. The film tab is the exception: a tile laid edge to edge across its 2 cells. It has Ink perforations and an Ink bottom row, and no side or top outline. Loose Glare pixels outside the outline are allowed for rays, teeth, glints and highlights.
e. Flat clay fills. Living things are stop motion clay that reads through motion, not texture: no thumbprints, no grain, no noise.
f. Draw the hero and the thorn crawler facing RIGHT; the game mirrors those two. Nothing else is ever mirrored: the moth, icicle, jelly and spark, and their elites, must read the same whichever way they move. Make them symmetric or front on, unless Stephen rules a render change. h. No words, letters or numbers in any game file. Labels go on review sheets only. Any word you ever draw follows these rules: no dashes, no exclamation marks, "Sky Wolf Studio" singular.
i. No real trademarks, logos or known characters.
j. Timing: the game runs 60 steps a second, and sprites change frame every 5 steps (12 fps) unless a row says otherwise.

3. HOW TO MAKE IT
Your own methods note of 24 September says it: do not ask the image tool for production pixel art. Use the image tool for concept pictures only, and build every game file as data:
1. Write each frame as a text grid: one string per frame, rows split by "/", one character per pixel. "." is clear; 0 to 9 and a to f are the key column above. A 12x16 frame is 16 rows of 12 characters.
2. Render it with render(), then run check(). Fix the grid, never the PNG.
3. Save the grid with save_source(): source/<stem>.txt, one line per frame, the frame name, a space, then the string.
4. Make enlarged copies only for review: whole number scale, nearest neighbour, with preview().
5. When a silhouette is unresolved, make one concept picture first: four clearly different silhouettes that stay readable at the target size. Use big shapes, clear negative space, no texture, no text and a flat mid grey background. Then rebuild the chosen one as a grid.

# SHUTTERBUG HELPER (Python with Pillow): run it at the start of every session, and again whenever the tool resets
import os, json, hashlib, zipfile
from PIL import Image
ROOT = '/mnt/data'                  # your sandbox's writable folder; if yours differs, change this one line
WORK = ROOT + '/shutterbug-work'
os.makedirs(WORK, exist_ok=True)
os.chdir(WORK)                      # every relative path below now lands inside the work folder
HEX = ['0b0a0f', '1f1a1d', '4a4a52', '8a8a90', 'c9c7c0', 'f2efe6', 'fbfbff', '6b3f2a',
       'e07a2b', 'c8302f', 'd83a9b', '2f5fd0', '3fb8b4', '3f9a3a', 'f2d13f', 'f0dcb0']
RGB = [tuple(int(h[i:i + 2], 16) for i in (0, 2, 4)) for h in HEX]
KEY = '0123456789abcdef'
INK, GLARE, WALNUT, SUN = 0, 6, 7, 14

def render(frames, w, h, path):
    # frames: one string per frame; rows split by '/'; '.' clear; 0-9 and a-f a palette index
    im = Image.new('RGBA', (w * len(frames), h), (0, 0, 0, 0))
    for f, s in enumerate(frames):
        rows = s.split('/')
        assert len(rows) == h, (path, f, 'rows', len(rows))
        for y, r in enumerate(rows):
            assert len(r) == w, (path, f, y, 'width', len(r))
            for x, c in enumerate(r):
                if c != '.':
                    im.putpixel((f * w + x, y), RGB[KEY.index(c)] + (255,))
    os.makedirs(os.path.dirname(path) or '.', exist_ok=True)
    im.save(path)

def check(path, w, h, n, sun=False, feet=False, allowed=None):
    # sun=True only for the hero and the beacon; feet=True for every hero file; allowed: the
    # palette indices the row names. Returns the indices used, for the manifest's colours field.
    im = Image.open(path)
    assert im.mode == 'RGBA' and im.size == (w * n, h), (path, im.mode, im.size)
    px, used = im.load(), set()
    for x in range(w * n):
        for y in range(h):
            p = px[x, y]
            assert p[3] in (0, 255), (path, x, y, 'alpha must be 0 or 255')
            if p[3]:
                assert p[:3] in RGB, (path, x, y, 'not one of the 16 colours')
                k = RGB.index(p[:3])
                assert sun or k != SUN, (path, x, y, 'Sun belongs to the hero and the beacon')
                assert allowed is None or k in allowed, (path, x, y, 'colour', k, 'is not named for this row')
                used.add(k)
    if feet:
        for f in range(n):
            assert any(px[f * w + x, h - 1] == RGB[INK] + (255,) for x in range(w)), (path, f, 'no Ink in the feet row')
    return sorted(used)

def save_source(stem, names, frames):
    # source/<stem>.txt: one line per frame, the frame name, a space, the string; post the same lines in the chat
    os.makedirs('source', exist_ok=True)
    with open('source/' + stem + '.txt', 'w') as fh:
        for n, s in zip(names, frames):
            print(n, s, file=fh)

def from_source(stem, w, h, path):
    # rebuild a game file from source/<stem>.txt (save posted lines there first with save_source)
    with open('source/' + stem + '.txt') as fh:
        frames = [ln.split(' ', 1)[1].strip() for ln in fh if ln.strip()]
    render(frames, w, h, path)

def preview(path, out, s=8):
    # a whole number enlargement, nearest neighbour, for review sheets only
    im = Image.open(path)
    os.makedirs(os.path.dirname(out) or '.', exist_ok=True)
    im.resize((im.width * s, im.height * s), Image.NEAREST).save(out)

def frame(path, w, f):
    # frame f of a strip, as its own image
    im = Image.open(path).convert('RGBA')
    return im.crop((f * w, 0, f * w + w, im.height))

def scale_nn(im, w, h):
    # nearest neighbour by pixel centres, as the game's canvas draws the 14x14 squash and the 10x18 stretch
    out = Image.new('RGBA', (w, h), (0, 0, 0, 0))
    src, dst = im.load(), out.load()
    for y in range(h):
        for x in range(w):
            dst[x, y] = src[(2 * x + 1) * im.width // (2 * w), (2 * y + 1) * im.height // (2 * h)]
    return out

def mirror(im):
    # the left facing copy the game draws for the hero and the thorn crawler
    out = Image.new('RGBA', im.size, (0, 0, 0, 0))
    src, dst = im.load(), out.load()
    for y in range(im.height):
        for x in range(im.width):
            dst[im.width - 1 - x, y] = src[x, y]
    return out

def glare_copy(im):
    # the dash's invulnerable steps: Sun and Walnut become Glare, every other pixel is kept
    out = im.copy()
    px = out.load()
    for y in range(out.height):
        for x in range(out.width):
            p = px[x, y]
            if p[3] and p[:3] in (RGB[SUN], RGB[WALNUT]):
                px[x, y] = RGB[GLARE] + (255,)
    return out

def sha(path):
    with open(path, 'rb') as fh:
        return hashlib.sha256(fh.read()).hexdigest()

# the backdrop under the sprites, for review plates only (the game's own blend)
BIOME = {'attic': (7, 4, 8), 'frost': (2, 5, 3), 'deep': (11, 2, 12),
         'overgrowth': (13, 4, 7), 'ember': (1, 3, 8)}   # solid tint, open tint, platform line
def mix(a, c, t):
    return tuple(int(a[i] + (c[i] - a[i]) * t + 0.5) for i in range(3))
def open_colour(k, b):    # an open photo cell of palette colour k (0 to 14) in biome b
    return mix(mix(RGB[k], RGB[3], 0.4), RGB[BIOME[b][1]], 0.2)
def solid_colour(k, b):   # a solid photo cell
    o = mix(RGB[k], RGB[3], 0.4)
    return mix(tuple(int(v * 0.6 + 0.5) for v in o), RGB[BIOME[b][0]], 0.35)

def pack(name):
    # zip the whole work folder to ROOT/<name>, test it, and return what to post
    path = os.path.join(ROOT, name)
    with zipfile.ZipFile(path, 'w', zipfile.ZIP_DEFLATED) as z:
        for d, _, files in os.walk(WORK):
            for f in sorted(files):
                p = os.path.join(d, f)
                z.write(p, os.path.relpath(p, WORK))
    with zipfile.ZipFile(path) as z:
        assert z.testzip() is None, (path, 'a damaged member')
        names = z.namelist()
        assert len(names) > 0 and {'manifest.json', 'progress.md'} <= set(names), (path, 'checkpoint is missing files')
    return path, len(names), os.path.getsize(path), sha(path)

def checkpoint(n):
    return pack('shutterbug-checkpoint-%02d.zip' % n)

def final():
    return pack('shutterbug-assets.zip')

def resume(zpath):
    # a new session: unpack the newest checkpoint into the work folder, then prove every finished file
    with zipfile.ZipFile(zpath) as z:
        z.extractall(WORK)
    with open('manifest.json') as fh:
        m = json.load(fh)
    for e in m['files']:
        assert sha(e['file']) == e['sha256'], (e['file'], 'sha256 differs from the manifest')
        if e.get('tool') == 'python grid':
            check(e['file'], e['w'], e['h'], e['frames'], sun=e['sprite'] in ('hero', 'beacon'),
                  feet=e['sprite'] == 'hero', allowed=e['colours'])
    return len(m['files'])

  kind is "strip" (an animation), "image" (one frame) or "tileset" (tiles repeated across cells; add "repeat": "x" or "y").

  names are the frame names the line gives; where it gives none, use a, b, c, d.
  fps is 0 for a held frame, and for frames the game picks by state or phase (the chest, the traps, the heart). loop is true for cycles.
  anchor is "bottom" (stands on its bottom row), "top" (hangs from its top row) or "cell" (floats inside its frame).
  facing is "right" for the hero, the thorn crawler and its elite, and "none" for every other file.
  colours lists the palette indices used: the list check() returns.
  tool is "python grid" for every game file, unless a ruling names another.

7. THE HERO IN DETAIL (batch 0)
Who: the Shutterbug, a thumb sized clay bug that fell out of the photo and climbs back up to the light. Dead Pixels, the game's currency, are the ones that never made it. Nothing else is fixed: its kind of bug, its legs, eyes and any camera or film detail are yours to propose.
It must:
- be 12x16 in every frame, the size of its hitbox, with Ink in the bottom row of EVERY frame: the feet row. Players must find its feet within 3 seconds at arm's length;
- have a Sun body, an Ink outline, Ink feet and a Glare eye. Walnut is allowed for clay detail. Use no other colour: the dash flash turns Sun and Walnut to Glare and keeps Ink;
- face right; the cling frame has its wall on the RIGHT;
- stand on its bottom centre. After a landing the game squeezes whatever frame shows into 14x14 for 6 steps. That is usually land, or run1 if a dash starts then, or fall if it runs off an edge. For 6 steps after any takeoff it stretches the frame into 10x18: jump, or dive, cling or fall if they start then. Never the dead frame. Design every frame to survive it;
- read on every biome and on the relit Sun lamp, where today's placeholder reads only by its outline.
How the game picks the frame, first match wins:
  dead;
  dive;
  cling: a wall slide, a vine or pipe hold, or rising along a wall with the rocker held toward it;
  jump while rising, else fall;
  run1 during a dash;
  land for 6 steps after any landing;
  run0 to run3 while moving;
  else idle0 and idle1.
On a vine or pipe, A jumps straight up 4 cells with no push off. The shared cling pose must not promise a sideways jump there.
Motion to fit:
  the run moves 2.6 px a step, so one 4 frame cycle covers about 52 px;
  a full jump rises about 70 px, and a fall reaches 12 px a step;
  a dash covers 3 cells in 8 steps.
Today's placeholder is in section 8. Reviews found five faults in it. At 360 px wide its feet are 1 px dots, the land squeeze reads as a squint, and the run moves only the legs. On the Sun lamp it reads only by its outline, and an early cling read as the letter i. Start from it or start fresh.
