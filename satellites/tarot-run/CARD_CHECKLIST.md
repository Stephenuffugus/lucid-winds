# Tarot Run — Card Art Checklist (78 cards)

_Generated from the live build. Paste into a Google Doc and tick as you go._

## How to upload (each card, ~1 min)
1. Make the art **512 × 720 px (5:7)**, cream-parchment background — see `ART_DIRECTION.md` for the Midjourney stem (paste it once, swap in the card name as the subject).
2. Save the PNG with the **exact filename** listed below (e.g. `card-wands-1.png`).
3. Drop it into the repo `art-slots/` folder and it auto-appears in-game on the live URL within ~1 min (no code change — `index.html` auto-loads `art-slots/{slot}.png`). Tell me when files are ready and I can wire/commit them.

**Priority:** do **★ TURN-ONE** cards first (they're in the Patron starter decks — every run shows them immediately, so the game looks finished fastest), then ②, ③, ④.
