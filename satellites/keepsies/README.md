# Keepsies (working title)

A realistic 3D marble game where the marbles are the economy: real Ringer in a ten foot ring, a turn based marble battle arena, one signature input (the Knuckle, the real thumb snap), and matches played for keeps.

No code yet. Read `docs/DESIGN.md` (the design, Stephen's) and `/HANDOFF-KEEPSIES.md` at the repo root (the build plan, Fable's, with the corrections that measurements forced). `sim/probes/` holds those measurements.
