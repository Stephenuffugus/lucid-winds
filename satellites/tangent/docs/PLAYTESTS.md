# Tangent playtests (the Director's own words, dated)

## 2026-09-02, Stephen, on his phone

> "tangent is getting fun but needs a lot more. you should be able to slide off the
> edge so you're kind of on a timer. there's almost no instructions. everything is
> very plain and boring."

Three asks, in order:

1. **Sliding off the edge ends the run.** Today the edge does not kill. He wants the edge
   to be a real fall so that every run is on a clock the player can feel. Design call:
   fall = instant loss of the run (Jimothy style, a "FLATTENED" beat), not a bounce.
2. **Instructions.** There are almost none. Needs a how-to card on first boot and a one
   line hint on the track for the first level (what the finger does, what the goal is).
3. **Skin it.** `ART_ASSETS.md` in the game folder is the list he generates from. Then
   tuning, then the fun pass.

Answered by: the ART_ASSETS.md list (this folder's parent), and a tuning task to be
briefed after he has played Deepwell and the Aug 16 sprint games too.
