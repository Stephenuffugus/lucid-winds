## The captcha loop
itch throws a captcha on **sign-up and login**, and it loops if the browser blocks
cookies/JS or you're on a locked-down network. Fixes, easiest first:
1. **Use your phone's normal browser** (Safari/Chrome), NOT a private/incognito tab and
   NOT an in-app browser (don't open itch from inside another app). Incognito is the #1
   cause of the captcha loop.
2. Make sure cookies + JavaScript are on. Chrome: ⋮ → Settings → Site settings → Cookies
   → "Allow". Safari: Settings → Safari → turn OFF "Block All Cookies".
3. If it still loops, switch networks — off wifi onto cell data (or vice versa). A VPN or
   a school/work network will trip it every time.
4. Different browser entirely (if you were on Chrome, try Safari). Fresh browser, fresh
   captcha.

Once you're in, you never fight it again — it's only the account gate.
