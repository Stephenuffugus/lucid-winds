# Lucid Winds / Sky Wolf — Game Art Asset Lists

Sprite-sheet prompt docs for generating game art, in the same format that skinned **Nectar Drop** (shared house STYLE block, titled contact sheets, magenta #FF00FF knockout, cell-by-cell prompts keyed to each game's real render code). Generate a sheet, hand it back, and it gets cut + wired.

**Workflow:** pick a game below by priority → open its `.md` → paste each Sheet's STYLE + prompt into your image generator → drop the PNGs to me → I cut (magenta-key knockout) and wire them in.
