# JIMOTHY SHEET 14J — Lane surfaces — tileable

Six cells, all TILEABLE left to right, all flat top down strips.

A boulevard and an expressway are currently the same grey. A surface lets a lane announce
what it is before you step on it, which is information rather than objects — it makes the
screen clearer, not busier. This is the single least cluttering thing on the whole pack.

## The nine cells

1. **Double yellow centre line** — a fast two way road.
2. **Lane dashes** — an ordinary street.
3. **Tram tracks set into the road** — a shared tram lane.
4. **Cobbles** — Pike Market.
5. **Dock boards** — the Waterfront and Ballard.
6. **Painted crosswalk** — the safe looking one. Which is a lie, and that is good design.

## Format
3 x 3 grid, **magenta #FF00FF** background, **white divider lines** between cells.
Side on, same camera and the same ground line as the existing vehicles, so they drop
straight into a lane. One sheet per image. Note a rough width per item ("about as wide as
a sedan" is fine) so the hitbox can be set honestly.

## Prompt
