# JIMOTHY SHEET 14I — Rail and freight

`railyard` and `tram-and-traffic` are two of the best set pieces in the plan and there
are exactly two rail sprites in the whole game.

⛔ The **tileable middle wagon** is the important cell. With it a freight train can be any
length, and a very long one grinding across a level is a real set piece for the cost of
one sprite.

## The nine cells

1. **Freight locomotive, front** — heavy, blunt, lights on.
2. **Freight wagon, TILEABLE MIDDLE** — must tile perfectly left to right. Boxcar.
3. **Freight wagon, tail** — the closing end.
4. **Flatbed wagon with strapped cargo** — an alternate middle, same tiling width.
5. **Level crossing road surface** — the planked strip where road meets rail. Tileable.
6. **Rail signal, STOP** — red aspect.
7. **Rail signal, CLEAR** — green aspect. The pair again.
8. **Handcar** — a pump trolley with two people. A slow, gentle rail lane for low tiers,
   so rails can appear early without being lethal.
9. **Caboose** — because it is a better tail than a plain wagon.

## Format
3 x 3 grid, **magenta #FF00FF** background, **white divider lines** between cells.
Side on, same camera and the same ground line as the existing vehicles, so they drop
straight into a lane. One sheet per image. Note a rough width per item ("about as wide as
a sedan" is fine) so the hitbox can be set honestly.
