# JIMOTHY SHEET 14C — Fremont — zone traffic

Fremont is the weird one and the traffic should be too. This is the sheet where you get
to be silly without it reading as clutter, because every item is still a single clean
silhouette moving in one direction.

## The nine cells

1. **Art car** — medium, medium, covered in glued-on junk and mirrors.
2. **Rocket parts on a flatbed** — very wide, slow. A fin and a nose cone strapped down.
3. **Dog walker with five dogs** — VERY wide, medium, leads fanned out. Nightmare fuel.
4. **Unicyclist** — narrow, fast, wobbling.
5. **Solstice parade float** — the widest thing here, very slow, streamers and flowers.
6. **Lenin statue on a low loader** — wide, slow, absurd, unmistakably Fremont.
7. **Moving truck with the ramp still down** — wide, medium.
8. **A couch carried by two people** — wide, slow, one person walking backwards.
9. **Scooter swarm** — four scooters in a loose cluster, wide, fast.

## Format
3 x 3 grid, **magenta #FF00FF** background, **white divider lines** between cells.
Side on, same camera and the same ground line as the existing vehicles, so they drop
straight into a lane. One sheet per image. Note a rough width per item ("about as wide as
a sedan" is fine) so the hitbox can be set honestly.
