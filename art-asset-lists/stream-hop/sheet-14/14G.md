# JIMOTHY SHEET 14G — Telegraph and signals — the fairness sheet

⛔ PAINT THIS ONE EARLY. It is small and it unlocks fair difficulty everywhere.

A five row gauntlet is cruel unless something warns you. Real Frogger design flips a
signal or flashes a light a beat before the traffic arrives. We currently have NOTHING
that says "something is coming", which means a hard pattern can only ever be made harder,
never fairer. These are small, they sit at the lane edge, and they add information rather
than objects — the opposite of clutter.

## The nine cells

1. **Walk signal, red hand lit** — post mounted, small, glowing red.
2. **Walk signal, green walk lit** — the SAME post, green. The pair is the whole point:
   a signal that can change is a promise the game can keep.
3. **Rail crossing, lights flashing, arm DOWN**
4. **Rail crossing, arm UP** — same post, cleared.
5. **Amber warning beacon on a pole** — slow rotating look.
6. **Klaxon burst** — drawn as a shape, radiating arcs. Never an emoji.
7. **Fast lane chevrons** — a road decal, painted arrows saying "this one is quick".
8. **One way arrow decal** — road surface, pointing right.
9. **Opposing arrow decal** — road surface, a pair pointing both ways.

## Format
3 x 3 grid, **magenta #FF00FF** background, **white divider lines** between cells.
Side on, same camera and the same ground line as the existing vehicles, so they drop
straight into a lane. One sheet per image. Note a rough width per item ("about as wide as
a sedan" is fine) so the hitbox can be set honestly.
