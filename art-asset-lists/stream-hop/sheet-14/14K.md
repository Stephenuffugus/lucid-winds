# JIMOTHY SHEET 14K — Two state set pieces — the ones with an idea in them

⛔ THIS IS THE FUN SHEET. Everything here is ONE object that has TWO states, which is how
you add a whole mechanic without adding a single new thing on screen. A drawbridge is not
clutter, it is a road that sometimes is not there.

Each pair must be the SAME object drawn twice, same size, same position, so the game can
flip between them cleanly.

## The nine cells

1. **Fremont drawbridge, DOWN** — a road you can cross. Full width.
2. **Fremont drawbridge, RAISED** — the same span, lifted, a gap where the road was.
   The most Seattle set piece available to us.
3. **Drawbridge mid lift** — one in between frame so the raise is not a jump cut.
4. **Crossing request button post** — a small pole with a lit button. Suggests the player
   can CHANGE a signal, which is a mechanic nobody expects in a hopper.
5. **Stopped bus, doors open** — a bus you can stand ON. A road lane that is briefly a
   platform, using road art for a water mechanic.
6. **The same bus, doors closed and moving** — now a hazard again. Same silhouette.
7. **Garbage truck, stopped with the arm down** — safe to stand behind, blocks the lane.
8. **The same garbage truck, arm up and rolling** — hazard.
9. **Boom gate lowered across a lane** — a temporary wall, reusable anywhere.

## Format
3 x 3 grid, **magenta #FF00FF** background, **white divider lines** between cells.
Side on, same camera and the same ground line as the existing vehicles, so they drop
straight into a lane. One sheet per image. Note a rough width per item ("about as wide as
a sedan" is fine) so the hitbox can be set honestly.
