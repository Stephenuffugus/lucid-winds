# Sheet 14 — the Jimothy course pack, one document per sheet

Twelve sheets. **We do not have to use all of them.** Drive copies live in
`012Assets / jimothy obstacles`.

⛔ Nothing here gets painted until `satellites/stream-hop/COURSE-PLAN.md` is approved. If
the pattern system changes shape, half this pack changes with it.

| sheet | what | why it earns its place |
|---|---|---|
| 14A | The Waterfront traffic | every zone currently draws the SAME pool, so six neighbourhoods look different and play identical |
| 14B | Pike Market traffic | the flying salmon is the best single hazard idea available |
| 14C | Fremont traffic | the weird zone gets weird traffic |
| 14D | Capitol Hill traffic | night, people rather than vehicles |
| 14E | Interbay traffic | slow, wide and heavy. Fixes the thin LATE/BIG bands carrying every level past 25 |
| 14F | Ballard Locks traffic | marine. Cell 6, eight people carrying a rowing shell, is the funniest hazard in the game |
| **14G** | **Telegraph and signals** | **paint early.** Small sheet, unlocks FAIR difficulty everywhere. We have nothing that says "something is coming" |
| 14H | Water set pieces | thirteen pads are all the same idea in a different hat. These give water states and consequences |
| 14I | Rail and freight | the tileable middle wagon means a freight train can be any length |
| 14J | Lane surfaces, tileable | a boulevard and an expressway are the same grey. Information, not objects |
| **14K** | **Two state set pieces** | one object, two states = a whole mechanic with nothing new on screen. The Fremont drawbridge |
| **14L** | **Quiet hazards** | small, cheap, mostly NOT lethal. The plastic bag that looks dangerous and is not. Fog that ADDS difficulty by REMOVING detail |

## Generate order
1. **14B** and **14E** — the two most different zones. They prove zone traffic works before
   you paint four more.
2. **14G** — small, and every hard pattern needs it to be fair.
3. **14K** and **14L** — the idea sheets. Most game per pixel on the whole list.
4. **14H**, then the remaining zones, then **14I**, then **14J**.

## House format
3 x 3, magenta #FF00FF, white divider lines, side on, one shared ground line, one sheet
per image. Tileable cells must tile cleanly left to right. Note a rough width per item.
