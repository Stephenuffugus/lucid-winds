# Sheet 03 — Monster-Claw Flippers (rest + flipped)

The two flippers rendered as clay monster claws (green mitts with 3 stubby fingers + thumb-dent), each in a rest pose and a raised/flexed pose, plus the brass pivot cap and a warm swing-glow underlay — top-down, pivoting at the base so the engine can rotate them about the pivot point.

```
STYLE — "Midnight Monster Lab" claymation (Blobworks pinball). Top-down 90 degree orthographic pinball art, hand-sculpted MODELLING CLAY / plasticine, stop-motion look (Aardman / Gumby / Morph). Every object is a little clay model: visible thumbprint dents, tool-scrape seams, soft rounded edges that wobble slightly (never perfectly geometric), matte plasticine sheen with ONE soft desk-lamp highlight, tiny pressed-in dust/lint flecks, a gentle contact shadow underneath. Goofy-friendly monsters — googly eyes, buck teeth, one stubby horn, big grins; cute NOT scary, no gore, no menace. Palette: dark clay lab-bench base #22202a, slate shadow #16151d; slime green #86d24a + deep monster teal #37b3a0; goop purple #9b6fd4; eyeball cream #f1ede2 with iris #4fa3d1 + black pupil; hazard yellow #f4c93a; danger red #e5533d; brass machine #c8a84b + warm lamp cream #efe6d2; gum-pink tongue #e88ba0. Lighting: one warm desk-lamp from top-center, cool moonlight fill, dark drop-off toward the middle of the table so the moving eyeball ball + bumpers pop. Rendering: photographed-clay feel — soft studio light, subtle grain, NO vector-flat, NO neon glow-blowout, NO photoreal humans, NO text / watermark / UI baked into sprites (letters are drawn by the engine). Everything reads at small size on a 540x960 phone table. Consistent top-down view for all playfield pieces (no perspective tilt). Deliver each sprite knocked out on a flat magenta #FF00FF background.
```

## Sheet layout

Generate the whole sheet at **2048x1536** on a pure, flat **magenta #FF00FF** knockout background (no gradient, no texture, no shadow cast onto the background). Lay it out as a strict **3 columns x 2 rows** grid of 6 equal cells (each cell ~682x768), equal margins and equal gutters so a fixed-pitch cutter can slice on a clean pitch. Keep every sprite fully inside its cell with generous padding, nothing touching a cell edge.

Cell assignment (left-to-right, top row then bottom row):
- Row 1: `flipper_L_rest` · `flipper_L_up` · `pivot_cap`
- Row 2: `flipper_R_rest` · `flipper_R_up` · `flipper_glow_underlay`

On-table render sizes (respect these — the engine draws at these pitches):
- Each claw flipper renders at about **82px long x ~34px tall** on the 540x960 table. Sculpt it as a HORIZONTAL claw with the **pivot at the base/wrist end** (the fat knuckle root) and the fingers reaching **inward toward table center**. Left claw base sits on the left, fingers point right; right claw is the mirror. Keep the two claws an obviously matched pair — same finger count, same knuckles, same colors, same buck-tooth-cute character — differing only by mirror and pose.
- `pivot_cap` renders at about **16px** across.
- `flipper_glow_underlay` renders as a soft blob roughly **96px x 44px**, sized to sit under and slightly larger than a swinging claw.
