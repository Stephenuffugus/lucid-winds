# Sheet 01 — Table Backdrops — 4 Lab Shifts

Four full-bleed 540x960 portrait playfield backdrops — one per `G.season` mood — that sit UNDER every playfield piece: lab furniture crowds the EDGES, the CENTER stays dark so the eyeball ball and clay pieces pop.

```
STYLE — "Midnight Monster Lab" claymation (Blobworks pinball). Top-down 90 degree orthographic pinball art, hand-sculpted MODELLING CLAY / plasticine, stop-motion look (Aardman / Gumby / Morph). Every object is a little clay model: visible thumbprint dents, tool-scrape seams, soft rounded edges that wobble slightly (never perfectly geometric), matte plasticine sheen with ONE soft desk-lamp highlight, tiny pressed-in dust/lint flecks, a gentle contact shadow underneath. Goofy-friendly monsters — googly eyes, buck teeth, one stubby horn, big grins; cute NOT scary, no gore, no menace. Palette: dark clay lab-bench base #22202a, slate shadow #16151d; slime green #86d24a + deep monster teal #37b3a0; goop purple #9b6fd4; eyeball cream #f1ede2 with iris #4fa3d1 + black pupil; hazard yellow #f4c93a; danger red #e5533d; brass machine #c8a84b + warm lamp cream #efe6d2; gum-pink tongue #e88ba0. Lighting: one warm desk-lamp from top-center, cool moonlight fill, dark drop-off toward the middle of the table so the moving eyeball ball + bumpers pop. Rendering: photographed-clay feel — soft studio light, subtle grain, NO vector-flat, NO neon glow-blowout, NO photoreal humans, NO text / watermark / UI baked into sprites (letters are drawn by the engine). Everything reads at small size on a 540x960 phone table. Consistent top-down view for all playfield pieces (no perspective tilt). Deliver each sprite knocked out on a flat magenta #FF00FF background.
```

## Sheet layout

- **Generate-at size:** each backdrop is its own **1080x1920** image (2x the on-table 540x960 so edge detail survives downscale). Deliver the set as a labeled **2x2 grid on a single 2160x3840 sheet** — four 1080x1920 panels, top-left `night`, top-right `day`, bottom-left `toxic`, bottom-right `power_out` — with a **12px magenta #FF00FF gutter** between panels and a **24px even magenta margin** all around, so a fixed-pitch cutter slices four clean panels. Alternatively deliver four separate 1080x1920 files. On-table each fills the whole 540x960 frame (full-bleed, blitted at 0,0).
- **Knockout:** the outer frame and gutters are flat, even **magenta #FF00FF** with no gradient/texture/spill. IMPORTANT — the backdrop art itself is NOT knocked out inside its panel: each panel is a full opaque 540x960 scene (dark bench fills corner to corner). Magenta appears ONLY in the gutters/margins that separate the four panels, so the cutter can find edges.
- **Center-dark discipline (all 4):** keep a roughly **300x600 px on-table oval in the middle** (≈600x1200 at 2x) in deep shadow — no furniture, no bright props. All shelves, jars, pipes, chalkboard, tools and the hanging lamp live in the outer ~90px border ring only. A warm desk-lamp pool blooms at **top-center** and fades to near-black by mid-table.
- **Framing trim (bake into all 4):** a sculpted clay **bench-edge lip** rings the whole frame (the outer wall), and two faint symmetric **lane-guide grooves** curve up the left and right thirds toward the top — pressed into the clay, unlit, barely-there so engine-drawn pieces sit on top.
