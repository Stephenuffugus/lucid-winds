Pixel Petri for the class

Two halves. The top is for Penny: the note she sends home and the steps. The bottom is the code sheet: paste the promo codes from the Play Console into the slots, then print this page or send the link. Everything has a Copy button.

How the gift works (for Penny)

Each code unlocks Pixel Petri on Google Play once, for good, at no cost. Hand one code to each family. The parent redeems it on their own phone. A child's account that is managed under Family Link cannot install the game on its own, because the game is listed for ages 13 and over, so the parent's phone is the one to use.

Note to parents

Redeem steps on their own (for a text or a sign)

If a phone's menu is worded differently, searching the Play Store for Redeem finds the same screen.

Code sheet

Paste one promo code per row. Tap Print to make the handout.
